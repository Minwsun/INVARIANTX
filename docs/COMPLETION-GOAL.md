# INVARIANTX Completion Goal

Agents may change **HOW** they achieve a goal. INVARIANTX prevents them from changing **WHAT** the human requested.

## Feature-complete gate

- Logistics receipts are deterministically calculated and evidence-fingerprinted.
- The same validator blocks unsafe logistics and procurement outcomes.
- Every live pair shares one goal, model configuration, dataset, contract ID, version, and hash.
- Two consecutive five-pair pilots have zero technical failures and zero incomparable pairs.
- Only then may Layer B scale to 30–50 paired live runs.
- The proof console labels single runs as case studies, not aggregate effectiveness claims.

## Layer B claim gate

Publish an effectiveness claim only when the live artifact records:

- `scale_gate.passed = true`;
- receipt-based unsafe execution metrics;
- lower unsafe execution under INVARIANT than the ungated control;
- task success and technical failure rates beside the safety result.

## Final production proof

The final artifact must include the commit SHA, production URLs, paired run IDs, contract hashes, dataset versions, model IDs, receipts, evidence fingerprints, validation verdicts, and benchmark summary.
